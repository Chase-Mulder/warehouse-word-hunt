# Warehouse Word Hunt: offline edition

A backup copy of the game for the KION end-of-year event (9 December 2026). Use it if GitHub Pages, YouTube or the Google scoreboard is blocked on a network, or the internet is unreliable.

The live website is not affected by anything in this folder.

**Download:** [WarehouseWordHunt-Offline.zip](https://github.com/Chase-Mulder/warehouse-word-hunt/raw/main/offline/WarehouseWordHunt-Offline.zip) (about 18 MB)

## How to run it

1. Download the zip and **unzip it** (Windows: right-click, then Extract All). Don't run it from inside the zip.
2. Open the extracted `WarehouseWordHunt-Offline` folder and **double-click `index.html`**. It opens in your normal browser (Edge, Chrome, Firefox or Safari).
3. Play exactly as on the website. Nothing is downloaded while you play: the game, every photo, the fonts and the intro video are all inside the folder.

**In a Teams breakout room:** one person opens `index.html` and shares their browser window (tick *Include sound* for the intro video), and the team calls out answers. Or everyone unzips their own copy.

## What's different offline

| Part | Offline behaviour |
|---|---|
| Shift leaderboard | No shared scoreboard. When a team finishes, the timer stops; they read their time to the moderator, who keeps scores in the chat. |
| Station 1 (Hitster) | The music clips come from YouTube, so the moderator plays them for the room (links below). Teams answer on screen as normal. |
| Intro video | Plays from `intro.mp4` in the folder. |
| Everything else | Same as the website, including the card studio and **Download card**. |

## Troubleshooting

- **Blank page or missing pictures:** make sure you unzipped first, and that `index.html` and `intro.mp4` are in the same folder.
- **A work laptop won't open local files in the browser:** try another browser, or have a teammate whose laptop works share their screen.
- **Start over:** press *Reset game* at the top of the page.
