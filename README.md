# Warehouse Word Hunt

An interactive, festive team puzzle game built for the KION End of Year virtual event (9 December 2026).

Nine stations, nine letters, one mystery word: music (Hitster), holiday food and greetings from around the world, two truths and a fake, a code-breaking wheel, a warehouse "Where's Waldo", chess, and a time-zone puzzle about who rings in the New Year first. Includes a 20-minute shift timer, animated fireworks and a New Year card studio.

Plain HTML, CSS and JavaScript: no build step. Photos and logos load from kiongroup.com. Open `index.html` or visit the GitHub Pages site.
